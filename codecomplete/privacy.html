Privacy Policy for Code Complete

Last updated: October 19, 2026

Code Complete is a JavaScript coding-practice app for iPhone, iPad and Mac. This policy explains how it handles your information. In short: Code Complete collects no data. There is no account, no analytics, no advertising and no tracking, and the app makes no network requests of its own.

Information we collect

None. Code Complete does not collect, store on a server, or share any personal information, usage data or diagnostics. It contains no analytics, crash-reporting or advertising software, and it does not access the advertising identifier.

Your code and progress

The code you write, your test results and your progress are stored only on your device, in the app's private storage. Your text-size preference is stored the same way. This data is not synced or sent anywhere, and the developer has no access to it. Deleting the app deletes it.

When you run your code, it executes in an isolated JavaScript sandbox on your device. The sandbox is not allowed to make network requests.

Third-party services

Code Complete uses no third-party services. The exercises are bundled with the app (adapted from the MIT-licensed Exercism JavaScript track), so nothing is downloaded while you use it. If you tap a link to an exercise's source, it opens in your web browser, which is covered by that website's own policies.

Children

Code Complete is suitable for all ages and collects no personal information from anyone, including children.

Changes to this policy

If this policy changes, the updated version will be posted on this page with a new "last updated" date.
